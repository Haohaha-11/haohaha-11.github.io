恭喜！你的 Hugo 学术网站项目已经准备就绪！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 第一步：安装 Hugo Extended
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在 PowerShell 或命令提示符中运行：

    winget install Hugo.Hugo.Extended

安装完成后，重启终端或 PyCharm。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 第二步：初始化项目
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式 A（推荐）：双击运行 init.ps1

方式 B：在 PowerShell 中运行：
    .\init.ps1

方式 C：手动执行：
    git init
    git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
    git submodule update --init --recursive

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✏️ 第三步：配置个人信息
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 编辑 hugo.yaml 文件，修改：
   - baseURL（你的 GitHub Pages 地址）
   - title（网站标题）
   - params.profileMode（个人信息）
   - params.socialIcons（社交链接）

2. 将你的头像保存为：static/img/avatar.jpg

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
👀 第四步：本地预览
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式 A：双击运行 start-server.bat

方式 B：在终端运行：
    hugo server -D

然后在浏览器打开：http://localhost:1313

按 Ctrl+C 停止服务器。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🌐 第五步：部署到 GitHub Pages
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 在 GitHub 创建新仓库（建议命名为 yourusername.github.io）

2. 推送代码：
    git add .
    git commit -m "Initial commit"
    git branch -M main
    git remote add origin https://github.com/yourusername/yourrepo.git
    git push -u origin main

3. 在 GitHub 仓库设置中：
   Settings > Pages > Source > 选择 "GitHub Actions"

4. 等待几分钟，访问你的网站！

💡 使用技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 在 Markdown 中嵌入 PDF：
   {{< pdf url="/pdfs/your-file.pdf" height="700px" >}}

2. 使用数学公式：
   行内：$E = mc^2$
   独立：$$\nabla \cdot \mathbf{E} = \frac{\rho}{\epsilon_0}$$

3. 插入图片：
   ![描述](/img/your-image.jpg)

4. 发布文章：
   将 draft: false 设置在文章开头

5. 保存草稿：
   将 draft: true 设置在文章开头

🆘 遇到问题？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题：Hugo 命令找不到
解决：重启终端或 PyCharm

问题：主题未加载
解决：运行 git submodule update --init --recursive

问题：数学公式不显示
解决：确保文章开头有 math: true

问题：PDF 无法预览
解决：检查文件路径，确保在 static/pdfs/ 目录

更多帮助请查看 SETUP.md 文件！
